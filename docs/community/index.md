# Community and support

OpenKCM is developed in the open, in the
[openkcm GitHub organization](https://github.com/openkcm). This page tells you
where to ask questions, report problems and security issues, and how to
contribute.

## Ask a question or report a problem

Open an issue in the repository of the service it concerns:

| Topic | Repository |
| --- | --- |
| The CMK service, its API, its Helm chart | [cmk](https://github.com/openkcm/cmk/issues) |
| The CMK UI | [cmk-ui](https://github.com/openkcm/cmk-ui/issues) |
| The Registry | [registry](https://github.com/openkcm/registry/issues) |
| ExtAuthZ | [extauthz](https://github.com/openkcm/extauthz/issues) |
| Session Manager | [session-manager](https://github.com/openkcm/session-manager/issues) |
| Checker | [checker](https://github.com/openkcm/checker/issues) |
| Keystore and identity management plugins | [keystore-plugins](https://github.com/openkcm/keystore-plugins/issues), [identity-management-plugins](https://github.com/openkcm/identity-management-plugins/issues) |
| Krypton | [krypton](https://github.com/openkcm/krypton/issues) |
| This documentation | [openkcm.github.io](https://github.com/openkcm/openkcm.github.io/issues) |

Include the versions of the charts and images you use, the relevant part of
your values (without secrets), and the log messages.

## Report a security vulnerability

Do **not** report security vulnerabilities in public issues. Report them
privately, as described in the
[OpenKCM security policy](https://github.com/openkcm/.github/blob/main/SECURITY.md):

- With a GitHub security advisory: in the affected repository, open the
  **Security** tab and select **Report a vulnerability**.
- By email to `openkcm-security@lists.neonephos.org`.

## Contribute

Contributions of code and documentation are welcome. Read the
[contribution guidelines](https://github.com/openkcm/.github/blob/main/CONTRIBUTING.md)
first:

- Sign off every commit under the Developer Certificate of Origin.
- Follow the [code of conduct](https://github.com/openkcm/.github/blob/main/CODE_OF_CONDUCT.md).
- Read the [guidelines for AI-generated contributions][genai] if you use such
  tools.
- Discuss larger features in an issue before you start.

To improve this site, see [Contributing to the documentation](/contribute/contributing)
and the [documentation style guide](/contribute/style-guide).
